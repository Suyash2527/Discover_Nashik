# Discover Nashik — Agent Context (read first)

Digital companion for Kumbh pilgrims: map-first PWA, voice assistant in Marathi/Hindi/English, works offline, admin advisories.

## Stack (₹0)
Next.js 16 (App Router) + TypeScript + Tailwind v4 · Leaflet + react-leaflet + OSM tiles ·
Firebase Spark (Auth + Firestore, advisories only) · Gemini free tier (`@google/genai`) ·
Web Speech API (primary voice) · Sarvam AI (optional) · Twilio trial (optional) · Vercel Hobby.

## Hard rules
- `/types` is LOCKED. Never edit it. Need a change? Stop and ask the human.
- Edit only folders you own (table below). Anything else: ask first.
- Places come only from `data/places.json` (generated by `npm run data` from `data/places.raw.csv`). Never invent or hardcode places.
- Voice answers: max 2 sentences, in the user's language, under 3 s.
- Everything except live Gemini answers must work offline.
- No paid APIs, no billing-card services, no Google Maps.
- Mobile-first, test at 375px width.
- Leaflet must be loaded client-only (`dynamic(() => import(...), { ssr: false })`).
- Small commits on your own branch: `feat/ui-*` (Antigravity), `feat/core-*` (Claude Code).

## Contracts
- `types/place.ts` — `Place`, `Category`, `CATEGORIES`
- `types/advisory.ts` — `Advisory` (Firestore `advisories/{id}`)
- `types/voice.ts` — `AskRequest`/`AskResponse` for `POST /api/ask`; `VoiceAssistant` hook shape
- `lib/voice/index.ts` — `useVoiceAssistant()`; currently a MOCK, same signature forever.

## Data
`data/places.raw.csv`: aliases separated by `|`. Run `npm run data` → converts + validates (bbox, ids, translations).
